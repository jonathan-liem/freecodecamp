## 🚀 Cara Menjalankan Proyek Secara Lokal

1. Clone repositori ini:
   ```bash
   git clone https://github.com/jonathan-liem/freecodecamp.git
   ```
2. Buka folder proyek:
   ```bash
   cd freecodecamp
   ```
3. Buka file `index.html` dari proyek mana pun langsung di browser (atau gunakan ekstensi *Live Server* di VS Code).
